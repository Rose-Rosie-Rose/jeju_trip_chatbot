# RAG 검색 실험 기록

## 실험 1. 기본 유사도 검색

- **목적:** PDF 임베딩 및 Chroma 유사도 검색의 기본 동작 확인
- **테스트 문서:** `sample.pdf`
- **페이지 수:** 2
- **청크 수:** 25
- **청킹 설정:** `chunk_size=500`, `chunk_overlap=100`
- **임베딩 모델:** `text-embedding-3-small`
- **검색 방식:** Chroma 기본 유사도 검색 (`similarity_search`)
- **검색 개수:** `k=3`

### 테스트 질문

대구 북구의 관광명소에는 무엇이 있어?

### 관찰 결과

1. 첫 번째 결과에서 관광명소 관련 정보가 확인됨.
2. 두 번째 결과에는 관광명소와 주소·운영 정보가 혼합되어 있음.
3. 세 번째 결과에는 숙박업소 정보가 포함되어 질문과의 관련성이 낮은 부분이 관찰됨.

### 개선 과제

- 질문에 직접적으로 관련된 문서를 더 잘 검색하는 방법 검토
- 검색 결과의 관련성과 답변 근거를 동일한 질문으로 비교
- 변경한 설정과 결과를 분리해서 기록

### 주의 사항

이번 결과는 단일 PDF와 단일 질문을 사용한 초기 관찰이다. 검색 품질 개선 여부를 확정하려면 여러 질문으로 추가 테스트해야 한다.
