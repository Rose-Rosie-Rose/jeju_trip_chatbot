# RAG 검색·답변 개선 기록

대상: `rag/chatbot.py` (기존 `test_pdf.py`를 옮김), 평가: `eval/eval_qa.py` 20문항 (feature/qa 브랜치)

## 기준 (개선 전)

- 청크: `chunk_size=800`, `chunk_overlap=150` (Tune_chunks 1위)
- 검색: 영어 질문 + 한국어 번역 질문으로 각각 벡터 유사도 검색 `k=4`
- 점수: **72.5점** (Tune_chunks 리포트와 재실행 결과 동일)
- 틀린 문항: 4, 7, 8, 12, 13, 16, 17, 20

## 남은 과제

- **20번**: 검색은 성공했으나 LLM이 "시원한 물을 부어 먹는다"를 "뜨겁지 않은 국물"로 연결하지 못함
- **4·8번**: 답 내용은 맞지만 채점 LLM이 부가 설명을 감점. 채점 기준 조정 검토
- **평가 편차**: 같은 코드도 실행마다 ±5점 차이. 비교할 때 최소 2~3회 평균 사용 권장
- **16번 평가 방식**: 앞 질문(12번)의 답에 따라 정답이 달라지므로, 기대 정답을 "12번에서 추천한 오름의 탐방 시간"으로 바꾸는 것을 검토
